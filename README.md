# IUB E-Portal System

A Java-based console application simulating the Islamia University of Bahawalpur's E-Portal. The system provides functionalities for both students and employees, including user authentication, timetable management, fee vouchers, and more.

## Features
- **User Authentication:** Sign up and sign in for students and employees.
- **Student Features:**
  - View timetable, transcript, and scholarships.
  - Manage course repetition and fee vouchers.
- **Employee Features:**
  - View work schedule, salary statements, and performance reviews.
  - Access employee benefits and active projects.
- Robust input validation and exception handling.

## Project Structure
- Main.java: Entry point of the application.
- User.java: Abstract class for user details and methods.
- Student.java: Handles student-specific functionalities.
- Employee.java: Handles employee-specific functionalities.
- IubEportal.java: Implements the core functionality and interfaces.

## Technologies Used
- Java (Object-Oriented Programming)
- Console-based input/output
- Exception handling for robust error management

## Future Improvements
- Add a database for persistent data storage.
- Enhance authentication with password hashing.
- Expand features to include real-time data management.
